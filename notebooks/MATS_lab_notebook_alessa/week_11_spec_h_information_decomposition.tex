\section{Question and final estimands}
For relearning prediction $F_t$, four-way gold label $Y$, and four-way
reference prediction $L$, Tier 1 is $I(F_t;Y)$.  Tier 3 is the functional
comparison $I(F_t;Y\mid L)$, with
$\mu=I(F_t;Y)-I(F_t;Y\mid L)$ and ratio $\mu/I(F_t;Y)$ when defined.
Both retain native four-way labels.  Tier 2, which conditions on the binary
correctness pattern $1[L=Y]$, is retained in JSON as a diagnostic only.
Its $\mu$ and ratio are not reported or interpreted. This is structural: an accurate reference makes the correctness variable constant, so a reference that explains everything can yield $\mu_2=0$. The preregistered scalar correctness null is independent of $Y$ and is therefore unmatchable; no post hoc class-conditional null is substituted.

Tier 1 is reported for retain-only ($N=512$) and forget-T ($N=102$).
Tier 3 is reported only for retain-only and labelled indicative: its
64-cell joint has about eight observations per cell.  Plugin and
Miller--Madow (MM) point estimates are stored.  The bootstrap uses 1,000
aligned item resamples and percentile 95\% intervals.  Tier 3 uses 20
matched symmetric four-way null draws.  Negative $\mu$ is not clipped.

\section{Exact-path regeneration and stop gate}
Each checkpoint was freshly loaded fp32 and wrapped in the same newly
initialized rank-256, alpha-512, all-linear PEFT adapter as the grid.  No
training occurred, so the LoRA update was zero.  Evaluation used the exact
grid scorer: right padding, Fisher prompt and letter-token parity,
colon-position hidden-state readout, bf16 CUDA autocast, fp32 softmax, and
float32 probability storage.  Full and options-only tables were regenerated.

Before decomposition, every fresh full table was compared with all six
retain-only step-zero tables for that checkpoint.  All 18 comparisons passed:
minimum argmax consistency was exactly 1.000000 and maximum absolute
probability delta was exactly zero for unfiltered, strong-filter, and CB.
Failure would have stopped the run.  For unfiltered versus the common intact
reference, the Tier 3 plugin ratio is exactly 1; MM gives
$0.9999999999999948$ from floating-point arithmetic.

\section{Pre-attack question--answer mutual information (Spec K)}
The information-at-floor quantity is not Tier 1.  Spec K instead computes
\[
 I(X;\widehat Y)=H(\bar p)-\frac{1}{N}\sum_x H(p(\cdot\mid x)),
 \qquad \bar p=\frac{1}{N}\sum_x p(\cdot\mid x),
\]
which contains no gold labels.  It was cross-checked against the equivalent
mean KL expression for every table.  Table~\ref{tab:spec-k} uses exact-path,
pre-attack tables; MI intervals use 1,000 question bootstrap resamples.

The proposed checks fail empirically: CB full MI is not near the family floor,
and CB options-only MI exceeds its full MI.  This is not a normalization bug:
the largest entropy-versus-KL discrepancy over all 402 tables was
$7.91\times10^{-16}$ nats and the largest probability-sum deviation was
$1.42\times10^{-7}$.  Options differ across questions even when stems are
removed, so options-only distributions can retain question-indexed variation.
The result is output-level only: it is neither accuracy nor
$I(\mathcal D_{\mathrm{forget}};\theta)$ and does not establish capability
absence.
\section{Prominent shortcut limitation --- since resolved}
The shortcut reference is the pre-attack options-only predictor. A negative
shortcut ratio shows only that recovery does not resemble that fixed
predictor. It does not by itself show that recovered accuracy is
question-dependent. That claim requires the post-recovery options-only
ablation, which had not been run at the time of writing.

\paragraph{Update --- the ablation has since run (Spec R).} Every checkpoint
on the 36-cell grid was subsequently evaluated in both modes in a single
invocation, and the question-dependent component is
$\Delta\mathrm{stem} = \mathrm{stem}(t_{\max}) - \mathrm{stem}(0)$, where
$\mathrm{stem}(t)$ is full-prompt accuracy minus options-only accuracy at the
same checkpoint. For \texttt{unfiltered-cb} under retain-only relearning ---
the one preregistered readout on this grid --- it is
$+0.148$ $[+0.090, +0.203]$, against a total accuracy gain of $+0.199$
($0.281 \to 0.480$). The caution was well placed and the direction it
anticipated holds: recovered accuracy is question-dependent in part, and the
negative shortcut ratio had not been sufficient evidence for it. The ablation
also bounds the claim in a way the ratio could not. The options-only component
is not static: it gains $+0.051$ over the same trajectory, so roughly a quarter
of the raw gain is option-intrinsic and the remainder is what
$\Delta\mathrm{stem}$ isolates. Zephyr RMU reproduces the shape under Spec R-Z
at $\Delta\mathrm{stem} = +0.200$ $[+0.156, +0.242]$ of a $+0.296$ total gain.

\section{Estimator caveat and conclusion}
MM-corrected Tier 3 point estimates can fall outside percentile bootstrap
intervals because occupied-cell counts, and hence the correction, change
across resamples at roughly eight samples per cell.  This instability is a
property of this small-cell estimator.  It is reported rather than hidden by
switching estimators.

The mismatch is now explained and repaired without rewriting the diagnostic
history. Exact probability-level self-consistency passes. Tier 1 is the primary result. Tier 3 is undetermined at this sample size because its intervals cross zero and plugin/MM estimates diverge; it is not used to select a favorable account. Tier 2 remains machine-readable
only as information associated with the binary pattern of reference
correctness, with no reported $\mu$ or ratio.
